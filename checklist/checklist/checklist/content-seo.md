# Content SEO Checklist

## Search Intent

- [ ] Primary search intent identified
- [ ] Search intent matches the page type
- [ ] Current SERP reviewed
- [ ] Top-ranking pages analyzed
- [ ] User's primary question is answered
- [ ] Content format matches user expectations

## Keyword Research

- [ ] Primary keyword identified
- [ ] Secondary keywords identified
- [ ] Related terms identified
- [ ] Search intent mapped to keywords
- [ ] Keyword cannibalization checked
- [ ] Keywords are used naturally

## Content Quality

- [ ] Content provides genuine value
- [ ] Topic is covered comprehensively
- [ ] Important information appears early
- [ ] Content is original
- [ ] Claims are factually accurate
- [ ] Statistics and data are updated
- [ ] Content is easy to understand
- [ ] Content avoids unnecessary repetition

## Topical Coverage

- [ ] Main subtopics covered
- [ ] Important entities covered
- [ ] Relevant related questions answered
- [ ] Content gaps identified against competitors
- [ ] Important user objections/questions addressed

## Content Structure

- [ ] Clear introduction
- [ ] Logical H2/H3 structure
- [ ] Short paragraphs used where appropriate
- [ ] Bullet points used where useful
- [ ] Tables used where they improve understanding
- [ ] Important information is easy to scan
- [ ] Relevant examples included

## Content Freshness

- [ ] Publish date reviewed
- [ ] Updated date reviewed where applicable
- [ ] Outdated information removed
- [ ] Broken references updated
- [ ] Old statistics replaced
- [ ] Changes in search intent considered

## E-E-A-T

- [ ] Author information available where relevant
- [ ] Author credentials provided where relevant
- [ ] First-hand experience demonstrated where appropriate
- [ ] Reliable sources referenced
- [ ] Publisher information available
- [ ] Trust signals are visible

## AI Search Readiness

- [ ] Key answers are clearly stated
- [ ] Important facts are easy to extract
- [ ] Definitions are concise and clear
- [ ] Relevant entities are clearly identified
- [ ] Content contains original insights where possible
- [ ] Tables/lists are used where they improve clarity
- [ ] FAQs address genuine user questions

# Metadata & SERP Checklist

## Title Tag

- [ ] Title tag exists
- [ ] Title is unique
- [ ] Primary keyword is included naturally
- [ ] Title accurately represents the page
- [ ] Search intent is reflected
- [ ] Title is compelling for users
- [ ] No keyword stuffing
- [ ] Important words appear early where appropriate
- [ ] Title is not unnecessarily repetitive

## Meta Description

- [ ] Meta description exists
- [ ] Meta description is unique
- [ ] Page topic is clearly explained
- [ ] Primary keyword/topic is included naturally
- [ ] Search intent is reflected
- [ ] Clear value proposition included
- [ ] CTA included where appropriate
- [ ] No keyword stuffing

## H1

- [ ] H1 exists
- [ ] H1 accurately describes the page
- [ ] Primary topic is reflected in H1
- [ ] H1 is unique on the page
- [ ] H1 is not unnecessarily long
- [ ] H1 matches search intent

## Heading Structure

- [ ] H2s cover major subtopics
- [ ] H3s are used logically under H2s
- [ ] Heading hierarchy is logical
- [ ] Headings help users scan the page
- [ ] Keywords are used naturally
- [ ] No headings are used only for styling

## Robots Meta

- [ ] Robots meta tag reviewed
- [ ] No accidental `noindex`
- [ ] No accidental `nofollow`
- [ ] Robots directives match SEO requirements

## Canonical

- [ ] Canonical tag exists where required
- [ ] Canonical points to preferred URL
- [ ] Canonical URL is absolute
- [ ] Canonical is indexable
- [ ] No conflicting canonical signals

## Open Graph

- [ ] `og:title` reviewed
- [ ] `og:description` reviewed
- [ ] `og:image` exists where appropriate
- [ ] `og:url` is correct
- [ ] `og:type` is appropriate

## SERP Preview

- [ ] Title reviewed in SERP context
- [ ] Meta description reviewed in SERP context
- [ ] Competitor SERP snippets reviewed
- [ ] Page communicates a clear reason to click

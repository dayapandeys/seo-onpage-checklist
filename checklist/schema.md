# Structured Data & Schema Checklist

## Schema Identification

- [ ] Relevant schema type identified
- [ ] Schema provides meaningful information about the page
- [ ] Schema type matches the actual page content
- [ ] Multiple schema types used only when appropriate

## Implementation

- [ ] Structured data implemented correctly
- [ ] Required properties included
- [ ] Recommended properties reviewed
- [ ] URLs are correct
- [ ] Organization/entity information is accurate
- [ ] Author information is accurate where applicable
- [ ] Dates are accurate
- [ ] Images use valid URLs

## Content Consistency

- [ ] Schema information matches visible page content
- [ ] No misleading structured data
- [ ] No outdated information
- [ ] Product information matches the page where applicable
- [ ] Review/rating information is genuine and visible where applicable

## Common Schema Types

- [ ] Article
- [ ] BreadcrumbList
- [ ] Organization
- [ ] WebSite
- [ ] WebPage
- [ ] Product
- [ ] LocalBusiness
- [ ] FAQPage where eligible and appropriate
- [ ] Person
- [ ] Other relevant schema types

## Validation

- [ ] Schema tested with a structured-data validation tool
- [ ] No syntax errors
- [ ] No critical validation errors
- [ ] Warnings reviewed
- [ ] Duplicate schema reviewed
- [ ] Google Search Console enhancements reviewed where applicable

## Maintenance

- [ ] Schema reviewed after major content changes
- [ ] Schema reviewed after template changes
- [ ] Dates updated where applicable
- [ ] Removed content is also removed from structured data

# Internal Linking Checklist

## Link Discovery

- [ ] Relevant internal linking opportunities identified
- [ ] Important target pages identified
- [ ] Existing internal links reviewed
- [ ] Orphan pages checked
- [ ] Broken internal links checked

## Contextual Links

- [ ] Links are contextually relevant
- [ ] Links help users discover related content
- [ ] Important pages receive relevant internal links
- [ ] Links are placed naturally within content
- [ ] Excessive linking avoided

## Anchor Text

- [ ] Anchor text clearly describes the destination
- [ ] Anchor text is relevant to the target page
- [ ] Exact-match anchors are not overused
- [ ] Generic anchors are minimized where descriptive text is possible
- [ ] Anchor text varies naturally

## Site Architecture

- [ ] Important pages are easy to reach
- [ ] Related pages are connected
- [ ] Topic clusters are properly linked
- [ ] Parent-child relationships are clear
- [ ] Content silos are supported where appropriate

## Link Equity

- [ ] High-value pages receive appropriate internal links
- [ ] Important pages are not excessively deep
- [ ] Internal links from authoritative pages reviewed
- [ ] Unnecessary internal links removed
- [ ] Navigation links reviewed

## Technical Checks

- [ ] Links use crawlable HTML
- [ ] Links point to canonical URLs where appropriate
- [ ] No broken links
- [ ] No unnecessary redirecting internal links
- [ ] No links to irrelevant pages

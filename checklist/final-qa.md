# Final SEO QA Checklist

## Search Intent

- [ ] Primary search intent confirmed
- [ ] Page satisfies the user's main need
- [ ] SERP reviewed before final approval

## On-Page

- [ ] Title tag checked
- [ ] Meta description checked
- [ ] H1 checked
- [ ] H2/H3 hierarchy checked
- [ ] Primary keyword mapped correctly
- [ ] Content reviewed for relevance
- [ ] Content reviewed for completeness

## URL & Canonical

- [ ] URL is correct
- [ ] URL is indexable
- [ ] Canonical is correct
- [ ] No unnecessary redirect
- [ ] Preferred URL version confirmed

## Indexability

- [ ] HTTP status code is correct
- [ ] Robots.txt reviewed where required
- [ ] Robots meta reviewed
- [ ] Page is indexable if intended
- [ ] Sitemap inclusion reviewed

## Internal Linking

- [ ] Relevant internal links added
- [ ] Important target pages linked
- [ ] Anchor text reviewed
- [ ] No broken internal links
- [ ] No unnecessary redirecting internal links

## Images

- [ ] Images are relevant
- [ ] Images are compressed
- [ ] Alt text reviewed
- [ ] Image dimensions reviewed
- [ ] Images load correctly

## Schema

- [ ] Relevant schema implemented
- [ ] Schema validated
- [ ] Schema matches visible content
- [ ] No critical errors

## Performance & UX

- [ ] Mobile experience checked
- [ ] LCP reviewed
- [ ] INP reviewed
- [ ] CLS reviewed
- [ ] Page loads correctly
- [ ] No major layout issues
- [ ] Important content is accessible

## Trust & Content

- [ ] Author information reviewed where relevant
- [ ] Sources reviewed
- [ ] Facts and statistics verified
- [ ] Publish/update date reviewed
- [ ] Contact/business information reviewed where relevant

## Final Verification

- [ ] Page source reviewed where required
- [ ] Google Search Console checked where applicable
- [ ] Competitor SERP results reviewed
- [ ] No accidental staging/test content
- [ ] No placeholder text
- [ ] No broken buttons or links
- [ ] Page is ready for publication

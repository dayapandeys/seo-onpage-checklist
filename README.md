# SEO On-Page Checklist

A practical, repeatable SEO framework for auditing and optimizing web pages for search engines, users, and modern search experiences.

## Overview

This repository provides a structured on-page SEO checklist that can be used for:

- New page launches
- Existing page optimization
- Content refreshes
- Technical SEO audits
- SEO quality assurance
- Competitor gap analysis
- Pre-publication reviews
- Post-optimization monitoring

## SEO Workflow

Use the repository as a repeatable workflow:

1. Understand the page
2. Identify search intent
3. Map primary and secondary keywords
4. Audit current on-page elements
5. Analyze content and competitor gaps
6. Optimize metadata and headings
7. Improve content
8. Strengthen internal linking
9. Review schema and technical SEO
10. Perform final SEO QA
11. Monitor performance

## Quick SEO Checklist

Before publishing or approving a page, verify:

- [ ] Search intent is clearly understood
- [ ] Primary keyword is identified
- [ ] Secondary keywords are mapped
- [ ] Title tag is optimized
- [ ] Meta description is optimized
- [ ] H1 is relevant and unique
- [ ] Heading hierarchy is logical
- [ ] Content satisfies search intent
- [ ] Important subtopics are covered
- [ ] Internal links are added
- [ ] Images are optimized
- [ ] Relevant schema is implemented
- [ ] Canonical is correct
- [ ] Indexability is verified
- [ ] Robots directives are reviewed
- [ ] Sitemap status is checked
- [ ] Mobile experience is reviewed
- [ ] Core Web Vitals are reviewed
- [ ] Final SEO QA is completed

## How to Use

### For a New Page

1. Identify the target audience and search intent.
2. Research and map relevant keywords.
3. Create the page structure.
4. Optimize title, meta description, H1, and headings.
5. Build useful, intent-focused content.
6. Add relevant internal links.
7. Implement appropriate structured data.
8. Complete technical SEO checks.
9. Run the Final SEO QA checklist.
10. Publish and monitor performance.

### For an Existing Page

1. Collect current performance data.
2. Review search intent and SERP results.
3. Audit the existing page.
4. Identify content and technical gaps.
5. Document recommendations.
6. Implement prioritized changes.
7. Re-check the page after implementation.
8. Monitor clicks, impressions, CTR, and average position.

## SEO Audit Principles

### Search Intent First

Optimization should begin with understanding what users are trying to accomplish with their search.

### User Value Over Keyword Density

Keywords should be incorporated naturally. Content should primarily serve the user's needs rather than a specific keyword frequency.

### Technical Accessibility

Search engines should be able to crawl, understand, and index the intended page.

### Clear Information Architecture

Content, headings, URLs, and internal links should make the relationship between pages clear to both users and search engines.

### Evidence-Based Optimization

Recommendations should be supported by relevant data such as Search Console performance, analytics, technical audits, search results, and competitor research.

### Continuous Improvement

SEO is an ongoing process. Pages should be reviewed and updated as search intent, competition, products, and business information change.

## Performance Monitoring

After optimization, monitor relevant performance indicators such as:

| Metric | Purpose |
|---|---|
| Clicks | Measure organic traffic generated |
| Impressions | Measure search visibility |
| CTR | Evaluate search-result engagement |
| Average Position | Track ranking changes |
| Organic Sessions | Evaluate traffic impact |
| Conversions | Evaluate business impact |

Performance should be evaluated over an appropriate period rather than based on short-term fluctuations.
